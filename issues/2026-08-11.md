# [화요일 · 노무·인사] 동물병원 근로계약, 이것만은 꼭 — 5인 기준과 필수 서류 점검

> **KAHA 회원병원 실무 소식지** · 2026-08-11 (화) · 발행: 한국동물병원협회
> 화요일은 병원 운영에 필요한 노무·인사 실무를 다룹니다. 일반적 안내이며, 개별 사안은 공인노무사 자문을 권합니다.

## 우리 병원은 '5인 이상'인가 — 모든 판단의 출발점

상시 근로자 수 5인을 기준으로 근로기준법 적용 범위가 크게 달라집니다. 원장(사업주)은 제외하고, 정규직·계약직·파트타임 **모두 포함**해 계산합니다.

| 구분 | 5인 미만 | 5인 이상 |
|---|---|---|
| 근로계약서 작성·교부 | 적용 | 적용 |
| 최저임금·주휴수당 | 적용 | 적용 |
| 퇴직금(1년 이상 근속) | 적용 | 적용 |
| 해고예고(30일 전) | 적용 | 적용 |
| 연장·야간·휴일 가산수당(50%) | 미적용 | 적용 |
| 연차유급휴가 | 미적용 | 적용 |
| 부당해고 구제신청 | 미적용 | 적용 |
| 직장 내 괴롭힘 금지 | 미적용 | 적용 |

야간 진료·주말 진료가 많은 동물병원 특성상, 5인 이상이 되는 순간 **가산수당 관리가 인건비의 핵심 변수**가 됩니다.

## 근로계약서 필수 기재사항 (근로기준법 제17조)

서면으로 작성해 **1부를 교부**해야 하며, 미작성 시 벌금 대상입니다.

1. 임금의 구성항목·계산방법·지급방법
2. 소정근로시간
3. 주휴일
4. 연차유급휴가(5인 이상)
5. 취업 장소와 종사 업무

**수의테크니션·미용사·리셉션** 등 직무가 다른 직원별로 업무 범위를 구체적으로 적어두면 이후 분쟁 예방에 유리합니다.

## 2026년 최저임금 반영 점검

- 시급 **10,320원** (2025년 10,030원에서 2.9% 인상)
- 주 40시간·월 209시간 기준 월급 **2,156,880원**
- 수습기간(최대 3개월)은 10% 감액 가능하나, **1년 미만 계약직과 단순노무직은 감액 불가**
- 포괄임금제를 쓰는 병원은 기본급 환산 시 최저임금 미달 여부를 연초에 반드시 재계산하세요.

## 이번 주 실무 체크리스트

- [ ] 전 직원 근로계약서가 서면 작성·교부되어 있는가 (교부 확인 서명 포함)
- [ ] 2026년 최저임금 인상분이 1월 급여부터 반영되었는가
- [ ] 상시 근로자 수 산정 결과, 우리 병원의 적용 법규를 정확히 알고 있는가
- [ ] 연장·야간(22시～06시)·휴일 근로 기록(출퇴근 기록)이 남고 있는가
- [ ] 임금명세서를 매월 서면(전자 포함)으로 교부하고 있는가
