# [목요일 · 경영·세무] 직원 한 명을 더 뽑으면 실제로 얼마가 드나 — 2026년 기준으로 계산해 봤습니다

> **KAHA 회원병원 실무 소식지** · 2026-08-20 (목) · 발행: 한국동물병원협회
> 목요일은 병원 경영·세무 실무를 다룹니다.

## 명목 급여만 보면 계산이 틀립니다

채용을 고민할 때 대부분 "월 300만원이면 연 3,600만원"으로 셈합니다. 실제로는 4대보험 사업주 부담분, 퇴직급여 적립, 연차수당까지 얹혀서 **명목 급여의 1.19～1.24배**가 나갑니다. 2026년은 특히 국민연금 요율이 오른 첫 해라 작년 계산을 그대로 쓰면 어긋납니다.

## 2026년에 달라진 것

| 항목 | 2025년 | 2026년 |
|---|---|---|
| 최저임금(시간급) | 10,030원 | **10,320원** (+2.9%) |
| 최저임금 월 환산(209시간) | 2,096,270원 | **2,156,880원** |
| 국민연금 총요율 | 9% | **9.5%** (사업주 4.75%) |
| 건강보험 요율 | 7.09% | **7.19%** (사업주 3.595%) |
| 장기요양보험 | 소득 대비 0.9182% | **0.9448%** (건강보험료의 13.14%) |
| 고용보험 실업급여 | 1.8% | 1.8% (동결) |

**국민연금 인상이 핵심입니다.** 2025년 연금개혁으로 2026년부터 8년간 매년 0.5%p씩 올라 2033년 13%에 도달합니다. 즉 **사업주 부담이 매년 0.25%p씩 자동으로 늘어납니다.** 인건비 계획을 세울 때 이 기울기를 반영해 두셔야 합니다.

## 사업주 부담률 — 2026년 약 10.6%

동물병원(150인 미만, 산재 '전문·보건·교육·여가관련 서비스업') 기준입니다.

| 항목 | 사업주 부담 |
|---|---|
| 국민연금 | 4.75% |
| 건강보험 | 3.595% |
| 장기요양보험 | 0.4724% |
| 고용보험 — 실업급여 | 0.9% |
| 고용보험 — 고용안정·직업능력개발(150인 미만) | 0.25% |
| 산재보험 — 업종요율 | 약 0.6% |
| 산재보험 — 출퇴근재해 | 0.06% |
| **합계** | **약 10.6%** |

2025년에는 약 10.3%였으므로 한 해 사이 0.35%p가량 올랐습니다.

산재 업종요율은 사업장마다 다르게 적용될 수 있습니다. 근로복지공단 홈페이지에서 사업자등록번호로 우리 병원 요율을 직접 조회해 확인하시는 편이 정확합니다.

## 여기에 더 붙는 것

- **퇴직급여 적립**: 연간 임금총액의 1/12, 즉 **약 8.33%**. DC형 사용자 부담금 기준입니다. 5인 미만 사업장도 퇴직금은 적용되므로 빠지지 않습니다.
- **연차유급휴가**: **5인 이상** 사업장만 해당합니다. 2년차 이상 15일 기준으로 환산하면 약 4.78% 수준입니다(15일 × 8시간 ÷ 2,508시간). 1년차는 최대 11일이므로 약 3.51%입니다. 연차사용촉진 절차를 적법하게 이행하면 미사용수당 지급 의무가 면제됩니다.
- **주휴수당**: 월급제에서 209시간을 적용하고 있다면 **이미 포함되어 있습니다**. (주 40시간 + 주휴 8시간) × 4.345주 ≈ 209시간이기 때문입니다. 따로 더하지 마세요.

## 계산해 보면

**월 300만원 직원 한 명 (5인 이상 병원)**

| 항목 | 금액 |
|---|---|
| 명목 급여 | 3,000,000원 |
| 4대보험 사업주 부담 (10.6%) | 약 318,800원 |
| 퇴직급여 적립 (8.33%) | 249,900원 |
| 연차수당 적립 (15일 기준 4.78%) | 143,400원 |
| **월 실질 인건비** | **약 3,712,000원** |
| **연간** | **약 4,455만원** |

명목 대비 **약 1.24배**입니다. 5인 미만이라 연차가 빠지면 약 1.19배, 월 약 357만원입니다.

**2026년 최저임금(월 2,156,880원) 기준**이면 월 실질 인건비는 약 267만원, 연간 약 3,203만원입니다.

## 줄일 수 있는 부분 — 두루누리 사회보험료 지원

- **사업장 요건**: 근로자 10명 미만
- **근로자 요건**: 월평균보수 270만원 미만인 **신규 가입** 근로자
- **지원 범위**: **국민연금과 고용보험만** (건강보험·산재보험은 제외)
- **지원 비율**: 근로자·사업주 부담분 각각 80%
- **지원 기간**: 최대 36개월
- **제외**: 전년도 재산 과세표준 합계 6억원 이상 또는 종합소득 4,300만원 이상

업종 제한이 없으므로 동물병원도 요건만 맞으면 대상입니다. 월 250만원 신규 채용자 기준으로 사업주 부담이 월 11만원가량 줄어듭니다. 채용 전에 요건을 확인해 두면 3년간 적지 않은 차이가 납니다.

청년(만 15～34세) 정규직 채용 시 **청년일자리도약장려금**도 있습니다. 다만 **반드시 참여 신청(사전 승인)을 거친 뒤에 채용**해야 하므로, 채용을 결정하기 전에 고용24(work24.go.kr)에서 절차를 먼저 확인하셔야 합니다.

## 실무 체크리스트

- [ ] 2026년 인건비 예산을 명목 급여의 1.2배 이상으로 잡았는가
- [ ] 국민연금 요율이 2033년까지 매년 오른다는 점을 중기 계획에 반영했는가
- [ ] 근로복지공단에서 우리 병원 산재보험 요율을 실제로 조회해 봤는가
- [ ] 신규 채용 예정자가 두루누리 지원 요건(10인 미만·월 270만원 미만·신규 가입)에 해당하는지 확인했는가
- [ ] 청년 채용을 계획 중이라면 채용 **전에** 지원사업 참여 신청을 했는가
- [ ] 5인 이상이 되는 시점에 연차 부담이 새로 발생한다는 점을 알고 있는가
