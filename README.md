# KAHA 회원병원 실무 소식지

한국동물병원협회(KAHA) 정책기획위원회가 회원병원 수의사를 위해 발행하는 요일별 실무 소식지입니다. 이 저장소가 소식지 사이트 전체이며, Vercel로 배포합니다.

- 특정 호 직접 링크: `/?d=2026-08-10`
- 이 저장소는 소식지 전용입니다. 개인 데일리 브리핑(vet-briefing 저장소)과는 별개로 운영합니다.

## 요일별 테마

| 요일 | 테마 | 다루는 내용 예시 |
|---|---|---|
| 월 | 진료 가이드라인 | WSAVA·ISFM·AAHA 등 최신 가이드라인 핵심 요약 |
| 화 | 노무·인사 | 근로계약, 최저임금, 연차, 4대보험, 직원 관리 |
| 수 | 서식·양식 | 동의서, 체크리스트 등 인쇄해 바로 쓰는 표준 양식(PDF) |
| 목 | 경영·세무 | 진료비 게시, 부가세, 손익 관리, 청구 실무 |
| 금 | 법규·정책 | 수의사법·마약류관리법 등 규제 대응, 정책 동향 |

테마는 `index.html` 상단의 `THEMES` 배열에서 수정할 수 있습니다. 뷰어는 발행 날짜의 요일로 테마 배지를 자동 표시합니다. 헤더의 검색창은 발행된 모든 호의 제목·본문을 검색합니다(archive.json 기반 자동 — 별도 관리 불필요).

## 발행 방법

1. `issues/YYYY-MM-DD.md` 파일을 작성합니다 (마크다운).
   - 첫 줄: `# [○요일 · 테마명] 제목`
   - 둘째 블록: 발행 정보 인용구(기존 호 형식 참고)
   - 말미에 출처와 면책 문구를 넣습니다.
2. **팩트체크(필수)**: 아래 「발행 전 팩트체크」 절차를 수행하고 `factcheck/YYYY-MM-DD.md`에 기록을 남깁니다. 팩트체크 기록이 없는 호는 발행하지 않습니다.
3. **인스타그램 카드뉴스**: `tools/cards_data.json`에 해당 날짜 항목(제목·부제·핵심 포인트 3개·캡션)을 추가하고 `python3 tools/make_cards.py YYYY-MM-DD`로 정사각형 카드(1080×1080) 5장과 caption.txt를 생성한 뒤, 호 말미에 「인스타그램 카드뉴스」 섹션(카드 이미지 + 복사용 캡션 코드블록, 기존 호 형식 참고)을 넣습니다. 캡션 요약도 해외 가이드라인 서술 원칙(소개 톤)을 따릅니다.
4. `archive.json`에 날짜를 추가하고 `latest`를 갱신합니다.
5. main에 커밋 & 푸시하면 Vercel이 자동 배포합니다.

## 법령 인용 원칙 (필수 — 2026-08-14 신설)

**법령 조문·조문 번호·수치를 인용할 때는 `reference/` 폴더의 원문을 대조합니다. 검색엔진 요약은 조문의 근거로 쓰지 않습니다.**

이 규칙은 실제 사고에서 나왔습니다. 검색 결과가 반복적으로 같은 값을 반환해 그것을 근거로 기존 기록까지 뒤집었으나, 원문 확인 결과 **검색이 틀렸고 원래 기록이 맞았습니다**(진료부 보존기간 1년을 3년으로 잘못 정정). 같은 검색엔진의 응답은 여러 번 조회해도 독립 출처가 아닙니다.

### 보유 중인 법령 원문 (`reference/`)

| 파일 | 법령 |
|---|---|
| `reference/수의사법.md` | 수의사법 [법률 제20087호] + 2026.11.13 시행 예정 개정 |
| `reference/수의사법시행령.md` | 수의사법 시행령 [대통령령 제34737호] |
| `reference/수의사법시행규칙.md` | 수의사법 시행규칙 [농림축산식품부령 제765호] |
| `reference/근로기준법시행령_별표1.md` | 근로기준법 시행령 [별표 1] — 상시 4명 이하 사업장 적용 규정 |
| `reference/근로자퇴직급여보장법.md` | 근로자퇴직급여 보장법 [법률 제21475호] + 제43조·제44조 2026.9.18 시행 개정 |

### 절차

1. **3단 구조를 함께 확인한다.** 법 → 시행령 → 시행규칙. 시행규칙만 보고 "이것뿐"이라고 쓰면 시행령에 있는 다른 유형을 놓칩니다. (실제 오류: 무면허 진료 예외를 시행규칙 제8조의 2가지로 단정했으나 시행령 제12조에 4유형이 있었음)
2. **조문 번호는 `reference/수의사법시행규칙.md` 말미의 「자주 틀리는 조문 번호」 표와 `수의사법시행령.md`의 「3단 구조 대조표」로 교차 확인한다.** (실제 오류: 진료비 게시 제20조→제20조의2, 예상비용 고지 제19조→제20조의3으로 잘못 인용)
3. **`reference/`에 없는 법령**(근로자퇴직급여 보장법·부가가치세법·폐기물관리법 등)의 조문·수치는 **원문 대조 없이 단정하지 않는다.** 다음 중 하나를 택한다.
   - 해당 내용을 **본문에서 뺀다** (기본)
   - **원장에게 확인을 요청**하고, 확인될 때까지 싣지 않는다 → `factcheck/확인요청.md`에 **어디서 무엇을 볼지** 구체적으로 적는다
4. **기존 기록과 새 검색 결과가 충돌하면, 원문 대조 전까지 기존 기록을 뒤집지 않는다.**
5. **아직 시행되지 않은 개정을 인용할 때는 "조문 번호가 그대로인지"를 확인한다.** 국가법령정보센터는 시행 전 개정이 있는 조문을 **한 조문 아래 두 버전으로 병기**하고, 개정 버전 끝에 `[시행일: YYYY. M. D.]`를 붙입니다. 형량·의무가 **다른 조문으로 옮겨가는** 경우가 있으므로 현행 조문 번호만 쓰면 틀립니다. 이때는 **"현행 제○조 → 시행일부터 제△조"** 형식으로 함께 씁니다. 시행일은 **부칙 제1조**(본문 시행일 + 단서의 개별 시행일)로 확인합니다.
   - (실제 오류: 퇴직금 체불 벌칙을 제44조로만 표기했으나 2026.9.18부터 **제43조로 이동**하면서 형량이 상향되는 구조였음)

### 확인 요청 방법

확인이 필요한 항목은 `factcheck/확인요청.md`에 우선순위별로 기록하고, 각 항목마다 **① 왜 필요한지 ② 어디서(정확한 사이트·메뉴·조문) ③ 무엇을 볼지 ④ 확인되면 어떻게 반영할지**를 적습니다. 원장이 조문을 그대로 붙여넣어 주면 `reference/`에 추가하고 본문에 반영합니다.

## 발행 전 팩트체크 (필수 절차)

모든 호는 발행 전에 다음 검증을 거칩니다. 창간 준비 검증에서도 실제로 오류가 발견·정정되었습니다(케타민 마약류 분류, NIMS 보고 기한, 진료비 게시 항목 수 — 각 호의 factcheck 파일 참고).

**검증 대상**: 본문에 등장하는 모든 ①숫자·금액·날짜(최저임금, 시행일, 기한 등) ②법령상 의무·범위·벌칙 ③가이드라인 권고 내용 ④제도명·기관명.

**검증 원칙**

1. **1차 출처 우선**: 법령은 국가법령정보센터(law.go.kr), 정책은 소관 부처(농림축산식품부·고용노동부·식약처) 발표, 가이드라인은 발행기관 원문(WSAVA·AAHA 등). 블로그·커뮤니티 글은 단독 근거로 쓰지 않습니다.
2. **최신성 확인**: 시행일·개정 이력이 있는 제도는 "지금(발행 시점) 기준"이 맞는지 확인합니다. (예: 진료비 게시 항목은 2024년 확대 후 2025년에 다시 20종으로 확대 — 구 기준 인용 주의)
3. **확실하지 않으면 싣지 않는다**: 검증 불가한 주장은 삭제하거나 "～로 알려져 있음, 원문 확인 필요"로 명시합니다. 조문 번호가 불확실하면 제도명으로만 씁니다.
4. **정정 기록**: 팩트체크 과정에서 고친 내용은 factcheck 파일의 「발행 전 정정 사항」에 남깁니다.

**기록 양식** (`factcheck/YYYY-MM-DD.md`)

```
# 팩트체크 기록 — YYYY-MM-DD (요일 · 테마)

검증일: YYYY-MM-DD · 검증 방법: (원문 대조 / 부처 발표 확인 등)

| # | 본문 주장 | 판정 | 근거 |
|---|---|---|---|
| 1 | ... | ✅ 확인 / ⚠️ 표현 수정 / ❌ 삭제 | 출처 링크 |

## 발행 전 정정 사항
- (없으면 "정정 없음"이라고 기록)
```

## 양식 PDF

수요일 서식 호의 양식은 **인쇄용 PDF와 수정 가능한 워드(DOCX) 두 형식**으로 `forms/`에 제공되어 소식지에서 바로 다운로드됩니다. 생성 스크립트는 PDF가 `tools/make_forms.py`(reportlab + 나눔고딕), 워드가 `tools/make_forms_docx.js`(docx npm, 기본 폰트 맑은 고딕)이며, 새 양식은 반드시 두 스크립트에 모두 추가해 같은 디자인 체계로 생성하고 소식지에 두 링크를 함께 넣습니다.

**디자인 규칙** — 브랜드 컬러는 공식 로고에서 추출한 KAHA 블루 `#035293`(제목·섹션 바·괘선 계열)와 차콜 `#231916`(본문). A4 한 장을 적절히 채우도록 행 높이를 조정하고, 표 셀 안의 글자가 두 줄로 꺾이지 않게 열 폭을 잡습니다. 각 양식에는 서식번호(KAHA-F-26XX)·시행일자 박스와 하단 발행처 표기를 넣습니다.

**동의서 계열 레이아웃(2026-08-18 개정)** — 동의서는 다음 구성을 표준으로 합니다. PDF는 `band_header()`·`divider()`·`cap()`, 워드는 `brandBand()`·`divider()`·`capBar()` 헬퍼를 재사용하면 두 형식이 같은 모양으로 나옵니다.

1. **상단 브랜드 밴드** — 짙은 파랑(`#023A68`) 바탕에 제목과 근거 법령을 흰 글자로, 오른쪽에는 흰 바탕 칸에 공식 로고. 서식번호 띠(`band_header`/`brandBand`의 `form_no` 인자)는 **내부 관리용 양식에만** 붙이고, 보호자에게 바로 배부하는 동의서에는 생략합니다.
2. **인적사항 표** — 보호자 / 반려동물 / 수의사 세 구획을 왼쪽 라벨 열 병합으로 묶고, 구획 경계에만 굵은 파란 선을 넣습니다.
3. **「설명 및 동의 사항」 구분선** — 가운데 정렬 제목 양옆에 가는 선.
4. **소제목 바** — 연한 파랑(`#EDF3FA`) 바탕에 가운데 정렬 제목, 왼쪽 끝에 파란 강조선(KAHA 식별 요소).
5. **본문·서명** — 법령 문언을 그대로 쓴 동의문 박스(연한 파랑 바탕 + 파란 테두리) 뒤에 작성일·보호자·설명 수의사 서명란.

워드는 모든 문단에 `LineRuleType.EXACT` 줄간격을, 모든 표 행에 `HeightRule.EXACT` 높이를 지정해 사용자의 폰트 환경과 무관하게 A4 한 장을 보장합니다. 생성 후에는 반드시 `libreoffice --headless --convert-to pdf`로 변환해 페이지 수가 1인지 확인합니다.

**보호자 배부용 동의서의 문구 원칙 (2026-08-18 원장 지시)** — 보호자가 직접 작성·서명하는 동의서에는 다음을 넣지 않습니다: 서식번호·시행일자 띠, 하단 발행처 및 "병원 실정에 맞게 수정 후 사용하십시오" 안내, 표 아래 출처·근거 표기("※ 출처 : …", "○○ 가이드라인 기반" 등). 인쇄해서 그대로 쓰는 문서이므로 병원이 채울 칸과 보호자가 읽을 내용만 남깁니다. 손으로 적는 칸(진단명·필요성·방법 및 내용 등)은 넉넉한 높이를 줍니다. 반면 원내 기록용 서식(체크리스트·기록지)에는 서식번호와 하단 표기를 유지합니다.

**다른 기관 서식 참고 시** — 레이아웃·구성은 벤치마킹하되, 수치를 옮길 때는 **먼저 근거를 검증하고 그 결과를 원장에게 보고**합니다. 검증되지 않은 수치를 그대로 쓸지는 원장이 결정하며, 결정 내용과 검증 경과는 반드시 `factcheck/`에 남깁니다(서류 자체에는 출처를 표기하지 않으므로 내부 기록이 유일한 근거가 됩니다). 웹 뷰어(`index.html`)의 색상 변수도 같은 팔레트를 사용합니다. 인스타 카드뉴스의 서체는 `assets/fonts/`의 Pretendard(OFL 라이선스, 제목 ExtraBold·소제목 Bold/SemiBold·본문 Regular)를 사용하며, tools/make_cards.py가 자동으로 참조합니다.

## 자동 발행 (매 평일)

평일 오전 6시(KST)에 자동 실행되는 Routine이 그날 테마의 소식지를 생성·팩트체크한 뒤 이 저장소 main에 푸시하고, Vercel이 즉시 배포합니다. 이미 준비된 호가 있는 날은 재검증 후 발행만 합니다.

**발행일 규칙** — 토·일은 발행하지 않습니다. **공휴일(대체공휴일 포함)은 평일이면 그대로 발행합니다**(2026-08-14 원장 확정). 일정을 미루거나 건너뛰지 않으므로 요일 테마도 그대로 유지됩니다. 콘텐츠 방침: **WSAVA·AAHA 등 무료 공개 가이드라인을 우선 인용**하고, 월·수요일은 가이드라인 기반 내용을 우선 편성합니다.

## 해외 가이드라인 서술 원칙 (필수)

WSAVA·AAHA 등 해외 가이드라인은 **국내 시행 의무가 없는 학술 권고**입니다. 유병률·사육 환경·유통 백신이 달라 우리나라 실정에 그대로 맞지 않을 수 있으며, 특히 백신 항목이 그렇습니다. 따라서:

1. **소개 톤으로 쓴다** — "시행해야 한다", "적용해야 한다"가 아니라 "이런 권고가 있다", "~하도록 권고합니다(해당 단체의 입장)"로 서술합니다. 권고의 주체(WSAVA·AAHA·미국 기준 등)를 문장에 명시합니다.
2. **국내 근거가 있으면 함께 제시한다** — 법령(예: 광견병의 가축전염병 예방법상 관리), 정부·검역본부 자료, 국내 학회 자료가 있으면 "국내 근거"로 구분해 소개합니다. 없으면 "국내 대규모 자료는 제한적"임을 밝히고 소개에 그칩니다.
3. **적용 판단은 병원 몫임을 명시한다** — 가이드라인 기반 호에는 상단에 "해외 가이드라인 소개에 대한 안내" 인용구를 넣고, 체크리스트는 "참고용 점검 포인트 (의무 아님)"로 표기합니다.
