# KAHA 회원병원 실무 소식지

한국동물병원협회(KAHA) 정책기획위원회가 회원병원 수의사를 위해 발행하는 요일별 실무 소식지입니다. 이 저장소가 소식지 사이트 전체이며, Vercel로 배포합니다.

- 특정 호 직접 링크: `/?d=2026-08-10`
- 이 저장소는 소식지 전용입니다. 개인 데일리 브리핑(vet-briefing 저장소)과는 별개로 운영합니다.

## 요일별 테마

| 요일 | 테마 | 다루는 내용 예시 |
|---|---|---|
| 월 | 진료 가이드라인 | WSAVA·ISFM·AAHA 등 최신 가이드라인 핵심 요약 |
| 화 | 노무·인사 | 근로계약, 최저임금, 연차, 4대보험, 직원 관리 |
| 수 | 서식·양식 | 동의서, 체크리스트 등 인쇄해 바로 쓰는 표준 양식(PDF) |
| 목 | 경영·세무 | 진료비 게시, 부가세, 손익 관리, 청구 실무 |
| 금 | 법규·정책 | 수의사법·마약류관리법 등 규제 대응, 정책 동향 |

테마는 `index.html` 상단의 `THEMES` 배열에서 수정할 수 있습니다. 뷰어는 발행 날짜의 요일로 테마 배지를 자동 표시합니다. 헤더의 검색창은 발행된 모든 호의 제목·본문을 검색합니다(archive.json 기반 자동 — 별도 관리 불필요).

## 발행 방법

1. `issues/YYYY-MM-DD.md` 파일을 작성합니다 (마크다운).
   - 첫 줄: `# [○요일 · 테마명] 제목`
   - 둘째 블록: 발행 정보 인용구(기존 호 형식 참고)
   - 말미에 출처와 면책 문구를 넣습니다.
2. **팩트체크(필수)**: 아래 「발행 전 팩트체크」 절차를 수행하고 `factcheck/YYYY-MM-DD.md`에 기록을 남깁니다. 팩트체크 기록이 없는 호는 발행하지 않습니다.
3. **인스타그램 카드뉴스**: `tools/cards_data.json`에 해당 날짜 항목(제목·부제·핵심 포인트 3개·캡션)을 추가하고 `python3 tools/make_cards.py YYYY-MM-DD`로 정사각형 카드(1080×1080) 5장과 caption.txt를 생성한 뒤, 호 말미에 「인스타그램 카드뉴스」 섹션(카드 이미지 + 복사용 캡션 코드블록, 기존 호 형식 참고)을 넣습니다. 캡션 요약도 해외 가이드라인 서술 원칙(소개 톤)을 따릅니다.
4. `archive.json`에 날짜를 추가하고 `latest`를 갱신합니다.
5. 양식을 만들거나 고쳤다면 **`python3 tools/check_forms.py`를 실행해 골든룰(A4 한 장)을 통과**시킵니다. 실패하면 발행하지 않습니다.
6. main에 커밋 & 푸시하면 Vercel이 자동 배포합니다.

## 법령 인용 원칙 (필수 — 2026-08-14 신설)

**법령 조문·조문 번호·수치를 인용할 때는 `reference/` 폴더의 원문을 대조합니다. 검색엔진 요약은 조문의 근거로 쓰지 않습니다.**

이 규칙은 실제 사고에서 나왔습니다. 검색 결과가 반복적으로 같은 값을 반환해 그것을 근거로 기존 기록까지 뒤집었으나, 원문 확인 결과 **검색이 틀렸고 원래 기록이 맞았습니다**(진료부 보존기간 1년을 3년으로 잘못 정정). 같은 검색엔진의 응답은 여러 번 조회해도 독립 출처가 아닙니다.

### 보유 중인 법령 원문 (`reference/`)

| 파일 | 법령 |
|---|---|
| `reference/수의사법.md` | 수의사법 [법률 제20087호] + 2026.11.13 시행 예정 개정 |
| `reference/수의사법시행령.md` | 수의사법 시행령 [대통령령 제34737호] |
| `reference/수의사법시행규칙.md` | 수의사법 시행규칙 [농림축산식품부령 제765호] |
| `reference/근로기준법시행령_별표1.md` | 근로기준법 시행령 [별표 1] — 상시 4명 이하 사업장 적용 규정 |
| `reference/근로자퇴직급여보장법.md` | 근로자퇴직급여 보장법 [법률 제21475호] + 제43조·제44조 2026.9.18 시행 개정 |

### 절차

1. **3단 구조를 함께 확인한다.** 법 → 시행령 → 시행규칙. 시행규칙만 보고 "이것뿐"이라고 쓰면 시행령에 있는 다른 유형을 놓칩니다. (실제 오류: 무면허 진료 예외를 시행규칙 제8조의 2가지로 단정했으나 시행령 제12조에 4유형이 있었음)
2. **조문 번호는 `reference/수의사법시행규칙.md` 말미의 「자주 틀리는 조문 번호」 표와 `수의사법시행령.md`의 「3단 구조 대조표」로 교차 확인한다.** (실제 오류: 진료비 게시 제20조→제20조의2, 예상비용 고지 제19조→제20조의3으로 잘못 인용)
3. **`reference/`에 없는 법령**(근로자퇴직급여 보장법·부가가치세법·폐기물관리법 등)의 조문·수치는 **원문 대조 없이 단정하지 않는다.** 다음 중 하나를 택한다.
   - 해당 내용을 **본문에서 뺀다** (기본)
   - **원장에게 확인을 요청**하고, 확인될 때까지 싣지 않는다 → `factcheck/확인요청.md`에 **어디서 무엇을 볼지** 구체적으로 적는다
4. **기존 기록과 새 검색 결과가 충돌하면, 원문 대조 전까지 기존 기록을 뒤집지 않는다.**
5. **아직 시행되지 않은 개정을 인용할 때는 "조문 번호가 그대로인지"를 확인한다.** 국가법령정보센터는 시행 전 개정이 있는 조문을 **한 조문 아래 두 버전으로 병기**하고, 개정 버전 끝에 `[시행일: YYYY. M. D.]`를 붙입니다. 형량·의무가 **다른 조문으로 옮겨가는** 경우가 있으므로 현행 조문 번호만 쓰면 틀립니다. 이때는 **"현행 제○조 → 시행일부터 제△조"** 형식으로 함께 씁니다. 시행일은 **부칙 제1조**(본문 시행일 + 단서의 개별 시행일)로 확인합니다.
   - (실제 오류: 퇴직금 체불 벌칙을 제44조로만 표기했으나 2026.9.18부터 **제43조로 이동**하면서 형량이 상향되는 구조였음)

### 확인 요청 방법

확인이 필요한 항목은 `factcheck/확인요청.md`에 우선순위별로 기록하고, 각 항목마다 **① 왜 필요한지 ② 어디서(정확한 사이트·메뉴·조문) ③ 무엇을 볼지 ④ 확인되면 어떻게 반영할지**를 적습니다. 원장이 조문을 그대로 붙여넣어 주면 `reference/`에 추가하고 본문에 반영합니다.

## 발행 전 팩트체크 (필수 절차)

모든 호는 발행 전에 다음 검증을 거칩니다. 창간 준비 검증에서도 실제로 오류가 발견·정정되었습니다(케타민 마약류 분류, NIMS 보고 기한, 진료비 게시 항목 수 — 각 호의 factcheck 파일 참고).

**검증 대상**: 본문에 등장하는 모든 ①숫자·금액·날짜(최저임금, 시행일, 기한 등) ②법령상 의무·범위·벌칙 ③가이드라인 권고 내용 ④제도명·기관명.

**검증 원칙**

1. **1차 출처 우선**: 법령은 국가법령정보센터(law.go.kr), 정책은 소관 부처(농림축산식품부·고용노동부·식약처) 발표, 가이드라인은 발행기관 원문(WSAVA·AAHA 등). 블로그·커뮤니티 글은 단독 근거로 쓰지 않습니다.
2. **최신성 확인**: 시행일·개정 이력이 있는 제도는 "지금(발행 시점) 기준"이 맞는지 확인합니다. (예: 진료비 게시 항목은 2024년 확대 후 2025년에 다시 20종으로 확대 — 구 기준 인용 주의)
3. **확실하지 않으면 싣지 않는다**: 검증 불가한 주장은 삭제하거나 "～로 알려져 있음, 원문 확인 필요"로 명시합니다. 조문 번호가 불확실하면 제도명으로만 씁니다.
4. **정정 기록**: 팩트체크 과정에서 고친 내용은 factcheck 파일의 「발행 전 정정 사항」에 남깁니다.

**기록 양식** (`factcheck/YYYY-MM-DD.md`)

```
# 팩트체크 기록 — YYYY-MM-DD (요일 · 테마)

검증일: YYYY-MM-DD · 검증 방법: (원문 대조 / 부처 발표 확인 등)

| # | 본문 주장 | 판정 | 근거 |
|---|---|---|---|
| 1 | ... | ✅ 확인 / ⚠️ 표현 수정 / ❌ 삭제 | 출처 링크 |

## 발행 전 정정 사항
- (없으면 "정정 없음"이라고 기록)
```

## 양식 PDF

### ⚠ 골든룰 — A4 한 장 (2026-08-18 원장 지시 · 최우선 규칙)

**모든 PDF와 워드 양식은 인쇄했을 때 내용이 A4 한 장 안에 다 들어와야 합니다.** 다른 어떤 요구보다 우선하며, 내용을 넣기 위해 이 규칙을 완화하지 않습니다. 넘칠 것 같으면 항목을 줄이거나 문구를 짧게 고칩니다.

"한 장"은 세 가지를 모두 뜻합니다.

1. **페이지 수가 1** — 두 장으로 넘어가지 않음
2. **잘린 글자가 없음** — 고정 높이 칸에서 글자가 잘려 인쇄되지 않는 곳이 없음
3. **인쇄 여백 확보** — 종이 끝에서 8mm 안쪽에 모든 내용이 있음(프린터 인쇄 불가 영역 대비)

**검사 방법** — 양식을 만들거나 고친 뒤 반드시 실행합니다. 실패하면 배포하지 않습니다.

```
python3 tools/make_forms.py && node tools/make_forms_docx.js && python3 tools/check_forms.py
```

`tools/check_forms.py`가 확인하는 것:

| 검사 | 방법 |
|---|---|
| PDF 페이지 수 | 1쪽인지 |
| PDF 인쇄 여백 | 그려진 모든 요소의 경계가 종이 끝에서 8mm 이상 안쪽인지 |
| 워드 페이지 수 | LibreOffice로 변환해 1쪽인지 |
| 워드 문구 보존 | 원문의 모든 문단이 변환 결과에 남아 있는지(칸에서 사라지지 않았는지) |
| **워드 칸 넘침** | 칸마다 필요한 높이를 직접 계산해 고정 높이와 비교 — 넘치면 실패 |
| **폰트 여유** | 글자가 6% 넓어져도 잘리지 않는지 — 사용자 PC의 폰트가 달라도 안전하도록 |

마지막 두 항목이 핵심입니다. 워드는 사용자 PC의 폰트로 다시 그리므로, "우리 환경에서 1쪽으로 보였다"는 근거가 되지 않습니다. 칸 높이가 EXACT로 고정돼 있어 글자가 한 줄 더 늘어나면 **페이지 수는 그대로인 채 그 줄만 잘려 인쇄**됩니다. 이 검사는 그 경우를 잡아냅니다.

**주의** — 워드 칸 안이 표로 끝나면 워드가 기본 높이(240 twips)의 빈 문단을 스스로 붙여 칸을 넘치게 합니다. `plainCell`이 아주 낮은 빈 문단을 자동으로 넣어 막고 있으니 우회하지 마십시오.


수요일 서식 호의 양식은 **인쇄용 PDF와 수정 가능한 워드(DOCX) 두 형식**으로 `forms/`에 제공되어 소식지에서 바로 다운로드됩니다.

### 배포 사이트 두 곳 — 사무국용 · 회원용 (2026-08-18 신설)

같은 양식을 두 주소로 제공합니다.

| 주소 | 대상 | 화면 |
|---|---|---|
| `/` (`index.html`) | 사무국 · 정책기획위원회 | 소식지 + 지난 호 검색 + **양식 모음** 버튼 |
| `/library/` (`library/index.html`) | **회원병원** | 양식만. 소식지·자동 발행 화면 없음 |

**두 사이트가 어긋나지 않게 하는 방법 — 코드와 데이터를 한 벌만 둡니다.**

| 공용 파일 | 하는 일 |
|---|---|
| `forms.json` | 양식 목록. 두 화면이 같은 파일을 읽습니다. |
| `assets/forms-view.js` | 양식 화면 전체(검색·분류 칩·목록)를 그리는 코드 |
| `assets/forms-view.css` | 양식 화면 스타일 |
| `assets/base.css` | 색·머리말·꼬리말 등 공통 기본 스타일 |

따라서 **양식을 고치고 `python3 tools/make_forms_manifest.py`만 다시 돌리면 두 사이트에 그대로 반영**됩니다. 화면 기능을 고칠 때도 위 공용 파일만 고치고, `index.html`이나 `library/index.html` 어느 한쪽에 기능을 따로 넣지 마십시오(한쪽만 좋아지면 회원이 보는 화면이 뒤처집니다).

`library/index.html`은 `KAHAForms.mount(element, { base: "../" })` 로 붙입니다. `base`는 `forms.json`과 `forms/` 폴더까지의 상대 경로입니다.

### ASA 등급표는 마취 동의서에만 (2026-08-18 원장 지시)

ASA 등급의 정의와 사망률 표는 **「수술등중대진료(마취) 동의서」 한 곳에만** 둡니다. 질환·처치별 동의서 136종에서는 뺐습니다. 마취를 하는 진료라면 마취 동의서를 함께 받으므로, 같은 표를 두 장에 싣는 셈이었습니다.

**빈자리는 반드시 내용으로 채웁니다.** 표를 빼서 생긴 자리(약 30mm, 여덟 줄 남짓)는 여백으로 두지 않고 다음에 씁니다.

| 넣은 것 | 분량 |
|---|---|
| **「질환에 대한 설명」 구획 신설** — 어떤 상태인지 · 왜 생기는지 · 두면 어떻게 되는지 | 3줄 |
| **후유증·부작용 항목 확대** — 기존 3~4개 → **6개** | +2줄 |

내용은 `data/procedures.json` 의 `about` 과 `risk` 이며, 원문은 `tools/content/proc_about_*.py` 에 나누어 두고 `python3 tools/apply_proc_about.py` 로 반영합니다. 이 배치에서 136종 전부가 레이아웃 사다리의 **맨 윗단(빈 줄 2줄 · 줄간격 12.6)** 을 유지합니다 — 병원이 직접 적을 빈 줄이 줄지 않았다는 뜻입니다.

**항목을 더 쓸 때 반드시 지킬 것 — 기존 목록과 겹치지 않게 하십시오.** 실제로 처음 작성분이 기존 `risk` 를 확인하지 않아 "재탈구가 발생할 수 있습니다" 옆에 "탈구가 다시 생기거나…" 를 나란히 싣는 일이 63건 있었습니다. 낱말 단위 비교로는 이런 중복이 잡히지 않으므로 **글자 2-gram 유사도로 대조**하십시오.

### 기입 칸 표기 규칙 (2026-08-18)

**고르는 항목은 빈칸이 아니라 체크칸으로 둡니다.** 병원마다 다르게 적히면 나중에 모아 볼 수 없고, 볼펜으로 적는 수고도 늘어납니다.

| 항목 | 표기 |
|---|---|
| 성별 · 중성화 | `□ 암  □ 수    □ 중성화` — 성별 하나를 고르고, 중성화했으면 함께 체크 |
| ASA 등급 | 표 왼쪽 체크 열 |
| CPR 시행 여부 | `□ 시행  □ 시행하지 않음(DNR)` |

이름·연락처·체중처럼 값이 정해지지 않은 것만 빈칸으로 둡니다.

**동의 선언문 아래의 "*기타 내용이 발생할 경우 별지를 포함합니다" 는 뺐습니다**(2026-08-18). 법이 요구하는 문구가 아니고, 서식번호·사용 안내를 없앤 것과 같은 이유입니다. 첨부물을 함께 받는 병원은 첨부물 자체에 서명을 받으십시오.

**발행 주체 표기 (2026-08-18 원장 지시)** — 화면·문서·소식지 어디에도 **「정책기획위원회」를 쓰지 않습니다.** 양식 자료실은 협회 전체의 업무이므로 **「사단법인 한국동물병원협회」**로만 표기합니다. (내부 검증 기록인 `factcheck/` 의 작성자 표기는 실제 작업 주체를 남기는 것이므로 그대로 둡니다.)

**진단명·시행 방법 칸** — 영문명을 병기하면서 값이 길어졌습니다. 칸 폭에 맞춰 글자를 줄이되 **읽을 수 있는 크기(7.6pt/워드 7.5pt)까지만** 줄이고, 그래도 넘치면 두 줄로 둡니다. 칸 높이는 두 줄이 들어가도록 11mm 로 잡아 **한 줄이든 두 줄이든 세로 가운데**에 오게 했습니다. 높이를 9mm 로 되돌리면 두 줄짜리 값이 칸 밖으로 삐져나옵니다.

**주의 — PDF는 연속 공백을 삼킵니다.** reportlab 의 `Paragraph` 는 HTML 처럼 이어진 공백을 하나로 합칩니다. 체크칸 사이를 벌려 놓아도 **인쇄하면 붙어 나옵니다**(워드는 `xml:space="preserve"` 라 그대로 나오므로, 두 형식이 다르게 보이는 원인이 됩니다). `form_style.py` 의 `keep_spaces()` 가 두 칸 이상을 `&nbsp;` 로 바꿔 `P()` 와 `bullets()` 에 자동 적용되니 우회하지 마십시오. **간격을 조정했으면 반드시 PDF를 그림으로 렌더링해 눈으로 확인**하십시오 — 글자 추출만으로는 공백이 합쳐진 것을 알 수 없습니다.

**근거 조문** — 동의서의 근거는 **「수의사법」 제13조의2 / 같은 법 시행규칙 제13조의2**입니다. 시행규칙 **제13조의3은 존재하지 않습니다**(2026-08-18 정정, `factcheck/2026-08-12.md` 참조). 조문을 쓸 때는 `reference/수의사법시행규칙.md` 원문과 그 파일 말미의 「자주 틀리는 조문 번호」 표를 **둘 다** 확인하십시오.

양식은 분류 폴더로 나누어 보관합니다. 새 양식을 추가할 때는 해당 분류 폴더에 넣습니다.

**양식을 추가하거나 이름을 바꿀 때의 순서**

1. `tools/make_forms.py`(PDF)와 `tools/make_forms_docx.js`(워드)에 양식을 추가합니다. 출력 경로에 분류 폴더를 포함시킵니다.

3. 세 스크립트를 차례로 실행합니다 — `python3 tools/make_forms.py && node tools/make_forms_docx.js && python3 tools/make_forms_manifest.py`
4. 양식을 소개하는 수요일 호를 쓸 때 `forms/분류폴더/파일명` 경로로 링크합니다.

`forms.json`은 양식 모음 화면(`index.html`의 '양식 모음' 버튼)이 읽는 매니페스트입니다. 손으로 고치지 말고 항상 스크립트로 다시 만듭니다.

**파일명 규칙 (2026-08-18 원장 지시)** — 회원이 내려받아 그대로 보관하는 파일이므로 `양식이름_한국동물병원협회.pdf` 형태의 한글 파일명을 씁니다(예: `마취동의서_한국동물병원협회.pdf`). 공백 대신 밑줄을 쓰고, 괄호·마침표 등 URL에서 문제가 되는 문자는 넣지 않습니다. 한글은 NFC로 저장하며, 파일명을 바꾸면 이를 링크한 `issues/*.md`를 함께 수정하고 두 생성 스크립트의 출력 파일명도 같이 바꿉니다. 생성 스크립트는 PDF가 `tools/make_forms.py`(reportlab + 나눔고딕), 워드가 `tools/make_forms_docx.js`(docx npm, 기본 폰트 맑은 고딕)이며, 새 양식은 반드시 두 스크립트에 모두 추가해 같은 디자인 체계로 생성하고 소식지에 두 링크를 함께 넣습니다.

- 구획 라벨과 보조 문구는 붙여서 **한 덩어리로 세로 가운데**에 오게 합니다.
- 수의사 구획에는 **수의사 성명**을 반드시 넣습니다(동물병원명·면허번호만 두지 않습니다).

**동의 선언문 원칙** — 포괄적 면책("어떤 일에 대해서도 일체의 민형사상 이의를 제기하지 않을 것을 서약")은 쓰지 않습니다(2026-08-18 원장 결정). 법원에서 효력이 부정되기 쉽고 불공정 조항으로 지적될 여지가 있어, **설명을 충분히 듣고 이해했다는 확인 + 시행 동의 + 수의학적 판단의 위임**으로 씁니다.

**보호자 서명 외에 설명 수의사 서명을 함께 받습니다** — 사무국 미용 양식에는 없으나, 수의사법 제13조의2 대상 동의서는 설명한 수의사를 특정해야 분쟁 시 방어가 됩니다.

### 워드 A4 1장 보장 (필수 · 절대 완화 금지)

원장 지시(2026-08-18): **워드 양식은 무조건 A4 한 장 안에 들어와야 합니다.** 사용자 PC의 폰트와 한국어 워드의 문서 그리드(`docGrid`)가 줄 높이를 밀어 올리기 때문에, "우리 환경에서 1장으로 보였다"는 근거가 되지 않습니다. 실제로 동의서가 이 문제로 한 번 넘쳤습니다(원인: 동의문 상자만 높이 미지정 + 그리드 스냅).

`tools/make_forms_docx.js`는 다음을 구조적으로 강제합니다. 새 양식을 추가할 때 이 장치를 우회하지 마십시오.

- **모든 표 행에 고정 높이** — `table(widths, rows, heights)`의 `heights`는 필수 인자입니다. 빠뜨리면 즉시 예외가 납니다. 행 높이는 `HeightRule.EXACT`로 나가므로 폰트가 달라져도 행 높이가 변하지 않습니다.
- **표 밖 요소 금지** — 본문 직속 요소는 `table()`·`gap()`·`noteRow()`·`header()`·`footerRow()`처럼 높이가 기록된 것만 씁니다. 주석 한 줄도 `para()`를 그대로 두지 말고 `noteRow()`로 감쌉니다(자동 높이 요소는 사용자 환경에서 늘어납니다).
- **빌드 시 높이 합계 검사** — `buildDoc(이름, 요소들)`이 `assertOnePage()`를 호출합니다. 높이 미지정 요소가 하나라도 있거나 합계가 `USABLE`(= A4 세로 − 상하 여백 − 안전여유 6mm)을 넘으면 **빌드가 실패**합니다. 실행하면 양식별 사용량과 여유가 출력됩니다.
- **문서 그리드 무력화** — 모든 텍스트 런에 `snapToGrid: false`를 지정합니다.
- **페이지 크기 명시** — 섹션에 A4(11906 × 16838 twips)를 직접 지정합니다(라이브러리 기본값에 의존하지 않음).
- **마지막 요소는 문단** — 본문이 표로 끝나면 워드가 빈 문단을 스스로 덧붙이고 그 높이는 통제할 수 없으므로, `buildDoc`이 끝에 고정 높이 `gap()`을 자동으로 붙입니다.

생성 후에는 `libreoffice --headless --convert-to pdf`로 변환해 페이지 수가 1인지 한 번 더 확인합니다(보조 확인일 뿐, 1차 보증은 위 검사기입니다).

**양식 문구 원칙 (필수 · 2026-08-18 원장 지시 — 전체 양식 적용)** — 배부용 동의서와 원내 기록용 서식을 가리지 않고 **모든 양식**에 적용합니다. 다음을 넣지 않습니다.

- **서식번호·시행일자 띠** (KAHA-F-26XX 등). 부제에도 쓰지 않습니다.
- **하단 발행처 표기와 "병원 실정에 맞게 수정 후 사용하십시오" 안내.** 하단 푸터 자체를 두지 않습니다.
- **출처·근거 표기** — "※ 출처 : …", "○○ 가이드라인 기반", "aaha.org 전문 무료 공개", "△△를 참고한 참고용 서식" 등. 부제는 그 양식이 무엇을 적는 문서인지만 한 줄로 씁니다.
- **다른 양식의 서식번호 참조** — "(서식 KAHA-F-2601)" 같은 상호 참조는 양식 이름으로 씁니다.

인쇄해서 그대로 쓰는 문서이므로 병원이 채울 칸과 보호자가 읽을 내용만 남깁니다. 손으로 적는 칸(진단명·필요성·방법 및 내용 등)은 넉넉한 높이를 줍니다. 근거 자료와 검증 기록은 서류가 아니라 `factcheck/`에 남깁니다.

**다른 기관 서식 참고 시** — 레이아웃·구성은 벤치마킹하되, 수치를 옮길 때는 **먼저 근거를 검증하고 그 결과를 원장에게 보고**합니다. 검증되지 않은 수치를 그대로 쓸지는 원장이 결정하며, 결정 내용과 검증 경과는 반드시 `factcheck/`에 남깁니다(서류 자체에는 출처를 표기하지 않으므로 내부 기록이 유일한 근거가 됩니다). 웹 뷰어(`index.html`)의 색상 변수도 같은 팔레트를 사용합니다. 인스타 카드뉴스의 서체는 `assets/fonts/`의 Pretendard(OFL 라이선스, 제목 ExtraBold·소제목 Bold/SemiBold·본문 Regular)를 사용하며, tools/make_cards.py가 자동으로 참조합니다.

## 자동 발행 (매 평일)

평일 오전 6시(KST)에 자동 실행되는 Routine이 그날 테마의 소식지를 생성·팩트체크한 뒤 이 저장소 main에 푸시하고, Vercel이 즉시 배포합니다. 이미 준비된 호가 있는 날은 재검증 후 발행만 합니다.

**발행일 규칙** — 토·일은 발행하지 않습니다. **공휴일(대체공휴일 포함)은 평일이면 그대로 발행합니다**(2026-08-14 원장 확정). 일정을 미루거나 건너뛰지 않으므로 요일 테마도 그대로 유지됩니다. 콘텐츠 방침: **WSAVA·AAHA 등 무료 공개 가이드라인을 우선 인용**하고, 월·수요일은 가이드라인 기반 내용을 우선 편성합니다.

## 해외 가이드라인 서술 원칙 (필수)

WSAVA·AAHA 등 해외 가이드라인은 **국내 시행 의무가 없는 학술 권고**입니다. 유병률·사육 환경·유통 백신이 달라 우리나라 실정에 그대로 맞지 않을 수 있으며, 특히 백신 항목이 그렇습니다. 따라서:

1. **소개 톤으로 쓴다** — "시행해야 한다", "적용해야 한다"가 아니라 "이런 권고가 있다", "~하도록 권고합니다(해당 단체의 입장)"로 서술합니다. 권고의 주체(WSAVA·AAHA·미국 기준 등)를 문장에 명시합니다.
2. **국내 근거가 있으면 함께 제시한다** — 법령(예: 광견병의 가축전염병 예방법상 관리), 정부·검역본부 자료, 국내 학회 자료가 있으면 "국내 근거"로 구분해 소개합니다. 없으면 "국내 대규모 자료는 제한적"임을 밝히고 소개에 그칩니다.
3. **적용 판단은 병원 몫임을 명시한다** — 가이드라인 기반 호에는 상단에 "해외 가이드라인 소개에 대한 안내" 인용구를 넣고, 체크리스트는 "참고용 점검 포인트 (의무 아님)"로 표기합니다.
