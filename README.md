# KAHA 회원병원 실무 소식지

한국동물병원협회(KAHA) 정책기획위원회가 회원병원 수의사를 위해 발행하는 요일별 실무 소식지입니다. 이 저장소가 소식지 사이트 전체이며, Vercel로 배포합니다.

- 특정 호 직접 링크: `/?d=2026-08-10`
- 이 저장소는 소식지 전용입니다. 개인 데일리 브리핑(vet-briefing 저장소)과는 별개로 운영합니다.

## 요일별 테마

| 요일 | 테마 | 다루는 내용 예시 |
|---|---|---|
| 월 | 진료 가이드라인 | WSAVA·ISFM·AAHA 등 최신 가이드라인 핵심 요약 |
| 화 | 노무·인사 | 근로계약, 최저임금, 연차, 4대보험, 직원 관리 |
| 수 | 서식·양식 | 동의서, 체크리스트 등 인쇄해 바로 쓰는 표준 양식(PDF) |
| 목 | 경영·세무 | 진료비 게시, 부가세, 손익 관리, 청구 실무 |
| 금 | 법규·정책 | 수의사법·마약류관리법 등 규제 대응, 정책 동향 |

테마는 `index.html` 상단의 `THEMES` 배열에서 수정할 수 있습니다. 뷰어는 발행 날짜의 요일로 테마 배지를 자동 표시합니다.

## 발행 방법

1. `issues/YYYY-MM-DD.md` 파일을 작성합니다 (마크다운).
   - 첫 줄: `# [○요일 · 테마명] 제목`
   - 둘째 블록: 발행 정보 인용구(기존 호 형식 참고)
   - 말미에 출처와 면책 문구를 넣습니다.
2. **팩트체크(필수)**: 아래 「발행 전 팩트체크」 절차를 수행하고 `factcheck/YYYY-MM-DD.md`에 기록을 남깁니다. 팩트체크 기록이 없는 호는 발행하지 않습니다.
3. **인스타그램 카드뉴스**: `tools/cards_data.json`에 해당 날짜 항목(제목·부제·핵심 포인트 3개·캡션)을 추가하고 `python3 tools/make_cards.py YYYY-MM-DD`로 정사각형 카드(1080×1080) 5장과 caption.txt를 생성한 뒤, 호 말미에 「인스타그램 카드뉴스」 섹션(카드 이미지 + 복사용 캡션 코드블록, 기존 호 형식 참고)을 넣습니다. 캡션 요약도 해외 가이드라인 서술 원칙(소개 톤)을 따릅니다.
4. `archive.json`에 날짜를 추가하고 `latest`를 갱신합니다.
5. main에 커밋 & 푸시하면 Vercel이 자동 배포합니다.

## 발행 전 팩트체크 (필수 절차)

모든 호는 발행 전에 다음 검증을 거칩니다. 창간 준비 검증에서도 실제로 오류가 발견·정정되었습니다(케타민 마약류 분류, NIMS 보고 기한, 진료비 게시 항목 수 — 각 호의 factcheck 파일 참고).

**검증 대상**: 본문에 등장하는 모든 ①숫자·금액·날짜(최저임금, 시행일, 기한 등) ②법령상 의무·범위·벌칙 ③가이드라인 권고 내용 ④제도명·기관명.

**검증 원칙**

1. **1차 출처 우선**: 법령은 국가법령정보센터(law.go.kr), 정책은 소관 부처(농림축산식품부·고용노동부·식약처) 발표, 가이드라인은 발행기관 원문(WSAVA·AAHA 등). 블로그·커뮤니티 글은 단독 근거로 쓰지 않습니다.
2. **최신성 확인**: 시행일·개정 이력이 있는 제도는 "지금(발행 시점) 기준"이 맞는지 확인합니다. (예: 진료비 게시 항목은 2024년 확대 후 2025년에 다시 20종으로 확대 — 구 기준 인용 주의)
3. **확실하지 않으면 싣지 않는다**: 검증 불가한 주장은 삭제하거나 "～로 알려져 있음, 원문 확인 필요"로 명시합니다. 조문 번호가 불확실하면 제도명으로만 씁니다.
4. **정정 기록**: 팩트체크 과정에서 고친 내용은 factcheck 파일의 「발행 전 정정 사항」에 남깁니다.

**기록 양식** (`factcheck/YYYY-MM-DD.md`)

```
# 팩트체크 기록 — YYYY-MM-DD (요일 · 테마)

검증일: YYYY-MM-DD · 검증 방법: (원문 대조 / 부처 발표 확인 등)

| # | 본문 주장 | 판정 | 근거 |
|---|---|---|---|
| 1 | ... | ✅ 확인 / ⚠️ 표현 수정 / ❌ 삭제 | 출처 링크 |

## 발행 전 정정 사항
- (없으면 "정정 없음"이라고 기록)
```

## 로고 (협회 공식 로고 적용됨)

협회에서 제공한 공식 로고 원본(AI)과 웹용 PNG가 `assets/`에 있습니다. 임의 제작 로고는 사용하지 않습니다.

- `kaha-logo.png` — 가로형(심볼+국문+영문), 뷰어 헤더·PDF 양식 머리에 사용
- `kaha-logo-vertical.png` — 세로형, 필요 시 표지·인쇄물용
- `kaha-logo-horizontal.ai` / `kaha-logo-vertical.ai` — 일러스트레이터 원본

## 양식 PDF

수요일 서식 호의 양식은 `forms/*.pdf`로 제공되어 소식지에서 바로 다운로드됩니다. **생성 스크립트는 `tools/make_forms.py`** 이며(reportlab + 나눔고딕), 새 양식은 반드시 이 스크립트에 추가해 같은 디자인 체계로 생성합니다.

**디자인 규칙** — 브랜드 컬러는 공식 로고에서 추출한 KAHA 블루 `#035293`(제목·섹션 바·괘선 계열)와 차콜 `#231916`(본문). A4 한 장을 적절히 채우도록 행 높이를 조정하고, 표 셀 안의 글자가 두 줄로 꺾이지 않게 열 폭을 잡습니다. 각 양식에는 서식번호(KAHA-F-26XX)·시행일자 박스와 하단 발행처 표기를 넣습니다. 웹 뷰어(`index.html`)의 색상 변수도 같은 팔레트를 사용합니다.

## 자동 발행 (매 평일)

평일 오전 6시(KST)에 자동 실행되는 Routine이 그날 테마의 소식지를 생성·팩트체크한 뒤 이 저장소 main에 푸시하고, Vercel이 즉시 배포합니다. 이미 준비된 호가 있는 날은 재검증 후 발행만 합니다. 콘텐츠 방침: **WSAVA·AAHA 등 무료 공개 가이드라인을 우선 인용**하고, 월·수요일은 가이드라인 기반 내용을 우선 편성합니다.

## 해외 가이드라인 서술 원칙 (필수)

WSAVA·AAHA 등 해외 가이드라인은 **국내 시행 의무가 없는 학술 권고**입니다. 유병률·사육 환경·유통 백신이 달라 우리나라 실정에 그대로 맞지 않을 수 있으며, 특히 백신 항목이 그렇습니다. 따라서:

1. **소개 톤으로 쓴다** — "시행해야 한다", "적용해야 한다"가 아니라 "이런 권고가 있다", "~하도록 권고합니다(해당 단체의 입장)"로 서술합니다. 권고의 주체(WSAVA·AAHA·미국 기준 등)를 문장에 명시합니다.
2. **국내 근거가 있으면 함께 제시한다** — 법령(예: 광견병의 가축전염병 예방법상 관리), 정부·검역본부 자료, 국내 학회 자료가 있으면 "국내 근거"로 구분해 소개합니다. 없으면 "국내 대규모 자료는 제한적"임을 밝히고 소개에 그칩니다.
3. **적용 판단은 병원 몫임을 명시한다** — 가이드라인 기반 호에는 상단에 "해외 가이드라인 소개에 대한 안내" 인용구를 넣고, 체크리스트는 "참고용 점검 포인트 (의무 아님)"로 표기합니다.

## 이메일·단체방 배포

배포 주소 링크(`/?d=날짜`)를 회원병원 단체 채널이나 메일로 공유하는 방식을 기본으로 합니다. 추후 뉴스레터 메일 발송 자동화가 필요하면 issues 마크다운을 HTML 메일로 변환하는 스크립트를 추가할 수 있습니다.
