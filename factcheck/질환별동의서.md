# 검증 기록 — 질환·처치별 동의서 136종

작성일: 2026-08-18 · 작성: 정책기획위원회

## 만든 방법

원장이 제공한 벳아너스 질환별 동의서(Screwtail, Superficial Keratectomy, CT 촬영 등)의
**구성**을 벤치마킹하고, 내용은 KAHA가 새로 작성했습니다. 문구를 옮겨 쓰지 않았습니다.

각 서식의 구성은 수의사법 제13조의2가 요구하는 설명 항목을 따릅니다.

| 항목 | 내용 |
|---|---|
| 진단명 | 해당 질환명 |
| 시행 방법 | 술식·처치명 (한글 + 영문 병기) |
| 진료의 필요성 · 방법 및 내용 | 2줄 |
| 전형적으로 발생이 예상되는 후유증 또는 부작용 | 2~4줄 (마취 동반 시 ASA 등급표 포함) |
| 진료 전후 보호자의 준수 및 숙지 사항 | 2~3줄 |
| 빈 줄 | 병원이 개체별 사항을 손으로 추가할 수 있도록 각 구획에 남김 |

## 내용 작성 원칙

1. **일반적으로 인정되는 합병증만 기재** — 특정 논문의 수치나 발생률은 넣지 않았습니다.
   숫자를 넣으면 그 근거를 서식마다 검증해야 하고, 병원별 실제 성적과 어긋날 수 있습니다.
2. **단정적 예후 표현 금지** — "완치됩니다", "재발하지 않습니다" 같은 표현을 쓰지 않았습니다.
3. **ASA 등급별 사망률**은 기본 마취 동의서와 같은 표를 씁니다
   (수치의 출처와 검증 경과는 `factcheck/2026-08-12.md` 참조).
4. **빈 줄을 반드시 남김** — 개체별 위험(고령·기저질환·해부학적 특수성)은 담당 수의사가
   직접 적도록 했습니다. 서식이 설명을 대체하지 않습니다.

## 원장 확인이 필요한 사항

- [ ] 136종의 **술식명 표기**(한글/영문)가 국내 개원가 관행에 맞는지
- [ ] 각 서식의 **후유증 목록에 빠진 중요 항목**이 없는지 (진료과별 검토 권장)
- [ ] 협회 명의로 배포하기 전, **진료과별 전문의 감수**를 거칠지 여부

이 서식들은 표준안이며, 개별 환자에 대한 설명 의무를 대신하지 않습니다.


## 2026-08-18 개정 — ASA 표 제거 · 질환 설명 신설

**원장 지시**: "마취 동의서에 ASA 등급 설명과 체크가 들어가니 개별 수술 동의서에서는 ASA 등급이 없어도 될 것 같고, 없어진 공간만큼 질병에 대한 설명이나 합병증이 더 들어가면 좋겠다."

| 항목 | 처리 |
|---|---|
| ASA 등급표 | 질환·처치별 동의서 136종에서 **제거**. 「수술등중대진료(마취) 동의서」에만 남김 |
| 「질환에 대한 설명」 구획 | **신설** — 136종 각각 3줄 |
| 후유증·부작용 | 기존 3~4개 → **6개**로 확대 |

### 작성 내용의 성격 — 감수 전임을 분명히 함

새로 넣은 「질환에 대한 설명」 136건과 추가 후유증 항목은 **수의학 교과서·임상 통념 수준의 일반적 서술**이며, **진료과별 전문의 감수를 아직 받지 않았습니다.** 개별 수치(발생률·성공률·생존기간 등)는 근거를 대조할 수 없어 **일부러 넣지 않았고**, "흔합니다 / 많습니다 / 드물게" 같은 정도 표현만 썼습니다.

배포 전 진료과별 감수가 필요하다는 점은 이 문서의 기존 기록과 동일하며, 이번 개정으로 **감수 대상 분량이 크게 늘었습니다**(설명 408줄 + 후유증 272줄).

### 작성 과정에서 잡은 오류

1차 작성분이 기존 `risk` 목록을 확인하지 않고 쓰여 **같은 내용을 두 번 싣는 일이 63건** 있었습니다(예: 슬개골 탈구 교정술 — "재탈구가 발생할 수 있습니다" 와 "탈구가 다시 생기거나 고정에 쓴 핀·와이어가 이동할 수 있습니다"). 낱말 단위 비교로는 잡히지 않아 **글자 2-gram 유사도**로 다시 대조해 총 **100건**(1차 63건 + 2차 37건)을 다른 항목으로 교체했습니다. 교체 내역은 `tools/content/proc_risk_fix.py` · `proc_risk_fix2.py` 에 남아 있습니다.
