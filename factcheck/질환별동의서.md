# 검증 기록 — 질환·처치별 동의서 136종

작성일: 2026-08-18 · 작성: 정책기획위원회

## 만든 방법

원장이 제공한 벳아너스 질환별 동의서(Screwtail, Superficial Keratectomy, CT 촬영 등)의
**구성**을 벤치마킹하고, 내용은 KAHA가 새로 작성했습니다. 문구를 옮겨 쓰지 않았습니다.

각 서식의 구성은 수의사법 제13조의2가 요구하는 설명 항목을 따릅니다.

| 항목 | 내용 |
|---|---|
| 진단명 | 해당 질환명 |
| 시행 방법 | 술식·처치명 (한글 + 영문 병기) |
| 진료의 필요성 · 방법 및 내용 | 2줄 |
| 전형적으로 발생이 예상되는 후유증 또는 부작용 | 2~4줄 (마취 동반 시 ASA 등급표 포함) |
| 진료 전후 보호자의 준수 및 숙지 사항 | 2~3줄 |
| 빈 줄 | 병원이 개체별 사항을 손으로 추가할 수 있도록 각 구획에 남김 |

## 내용 작성 원칙

1. **일반적으로 인정되는 합병증만 기재** — 특정 논문의 수치나 발생률은 넣지 않았습니다.
   숫자를 넣으면 그 근거를 서식마다 검증해야 하고, 병원별 실제 성적과 어긋날 수 있습니다.
2. **단정적 예후 표현 금지** — "완치됩니다", "재발하지 않습니다" 같은 표현을 쓰지 않았습니다.
3. **ASA 등급별 사망률**은 기본 마취 동의서와 같은 표를 씁니다
   (수치의 출처와 검증 경과는 `factcheck/2026-08-12.md` 참조).
4. **빈 줄을 반드시 남김** — 개체별 위험(고령·기저질환·해부학적 특수성)은 담당 수의사가
   직접 적도록 했습니다. 서식이 설명을 대체하지 않습니다.

## 원장 확인이 필요한 사항

- [ ] 136종의 **술식명 표기**(한글/영문)가 국내 개원가 관행에 맞는지
- [ ] 각 서식의 **후유증 목록에 빠진 중요 항목**이 없는지 (진료과별 검토 권장)
- [ ] 협회 명의로 배포하기 전, **진료과별 전문의 감수**를 거칠지 여부

이 서식들은 표준안이며, 개별 환자에 대한 설명 의무를 대신하지 않습니다.
