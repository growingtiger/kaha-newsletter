## 검증했으나 본문에서 제외한 항목

- 소득세법·시행령·조세특례제한법 조문 번호 — 원문 미보유 → 제도명으로만 표기. (검색 결과 간에도 전문직 범위를 정한 시행령 조문 번호가 제147조의2 / 제147조의3으로 엇갈림)
- 인건비 예외 거래의 구체적 대상 — 자료마다 요약이 달라 제외.
- 배제되는 세액감면의 종류 — 원문 미열람, 동물병원 해당 여부 불명 → 이름을 쓰지 않음.
- "사업용 계좌 미신고·미사용 시 세무서장이 경정(조사)할 수 있다" — 2차 자료에서만 확인 → 제외.
- "가산세는 산출세액이 없어도 부과된다" — 2차 자료에서만 확인 → 제외.
- 미신고 가산세의 일수 안분 산식(미신고 일수 ÷ 365 등) — 자료마다 표현이 달라 "신고하지 않은 기간의 수입금액"으로만 서술하고, 예시는 1년 전체 미신고로 한정.
- 공동사업자의 계좌 신고 방식 — 확인 자료 없음 → 제외.
- 홈택스 메뉴 경로 — 개편이 잦고 현재 화면을 확인할 수 없어 메뉴 이름만 안내.

## 발행 전 정정 사항

- 초안의 "법인 동물병원에는 이 제도가 적용되지 않습니다" → 법인 쪽 규정을 원문으로 확인하지 못했으므로 "소득세법상 개인사업자에게 적용되는 제도"로 고침.
- 초안의 "사업용 계좌에서 개인 생활비가 빠져나가는 것 자체가 가산세 대상은 아니지만" → 근거 자료가 직접 뒷받침하지 않아 삭제.
- 초안의 "같은 화면에서 신고된 계좌를 조회할 수 있습니다" → 현재 홈택스 화면을 확인할 수 없어 단정하지 않는 표현으로 고침.
