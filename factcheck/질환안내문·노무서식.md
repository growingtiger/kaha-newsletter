## 질환 안내문 (보호자 설명용) 60종

동의서가 아니라 **보호자에게 건네는 설명 자료**입니다. 구성은 어떤 질환인가요 / 증상 /
진단과 치료 / 가정 관리 / 응급 신호 / 담당 수의사 메모입니다.

### 작성 원칙

1. **널리 인정되는 임상 소견만** 기재했습니다. 발생률·생존율·특정 약물 용량은 넣지 않았습니다.
   숫자를 넣으면 서식마다 근거를 검증해야 하고, 개체·병기에 따라 달라져 오해를 부릅니다.
2. **단정적 예후 표현 금지** — "완치됩니다", "재발하지 않습니다" 같은 표현을 쓰지 않았습니다.
3. **약물명·상품명 미기재** — 처방은 담당 수의사의 판단 영역이므로 "약물로 조절합니다" 수준으로만 적었습니다.
4. **응급 신호를 반드시 포함** — 보호자가 언제 병원에 와야 하는지가 안내문의 실질적 가치입니다.
5. **담당 수의사 메모 칸**을 두어 개체별 설명을 손으로 적도록 했습니다.

### 원장 확인이 필요한 사항

- [ ] 진료과별 감수 — 특히 심장·내분비·종양 항목의 표현
- [ ] 병원 사정에 맞지 않는 안내(예: 특정 검사 접근성)가 있는지
- [ ] 협회 명의 배포 전 대표 몇 종을 표본 검토할지

## 노무·행정 서식 41종

### 법령 인용을 서식에 넣지 않은 이유

이 저장소의 「법령 인용 원칙」에 따라, **원문을 대조하지 못한 조문 번호는 인용하지 않습니다.**
`reference/` 에는 수의사법 3단과 근로기준법 시행령 별표 1, 근로자퇴직급여보장법만 있고
근로기준법 본문이 없습니다. 따라서 서식 본문에는 조문 번호를 쓰지 않고
**"관계 법령이 정하는 바에 따릅니다"** 로 표현했습니다.

이는 원장 지시(서류에 출처·근거 표기를 넣지 않는다)와도 방향이 같습니다.

### 서식 설계 시 반영한 실무 요소

| 서식 | 반영 사항 |
|---|---|
| 근로계약서 | 계약기간·근무장소·업무내용·소정근로시간·휴일·임금·지급방법을 각 칸으로 분리, 2부 작성 문구 |
| 단시간 근로계약서 | 시간급과 요일별 근무 기재, 비례 연차 안내 |
| 연차 신청서 | 반차·시간 단위 선택, 잔여 연차 기재란 |
| 초과근무 신청서 | 연장·야간·휴일 구분, 사전 승인 원칙, 수당/보상휴가 선택 |
| 연차 사용 촉진 통보서 | 미사용 일수·사용 기한·회신 기한·근로자 시기 지정란 |
| 퇴직 확인서 | 임금·연차수당 정산, 4대보험 상실 신고, 물품·권한 회수 체크 |
| 마약류 관리 대장 | 사용·잔량·폐기 기록, 잠금 보관과 불일치 시 보고 안내 |
| 산업재해·교상 기록지 | 광견병 접종 확인란, 응급조치와 재발 방지 |

### 원장 확인이 필요한 사항

- [ ] **근로계약서·연봉계약서·수습 합의서**는 노무사 검토를 권장합니다.
      임금 구성(포괄임금 여부), 수습 감액, 계약 갱신 조항은 분쟁 소지가 큽니다.
- [ ] 취업규칙이 있는 병원은 경조사 휴가 일수 등을 규칙과 맞춰야 합니다.
- [ ] 의료폐기물·마약류 대장은 각 병원의 실제 보고 체계와 항목이 맞는지 확인이 필요합니다.

두 계열 모두 **표준안**이며, 개별 사안에 대한 법률·노무 자문을 대신하지 않습니다.
